# Smart Study Assistant

An AI-powered study assistant built using:
- Python
- Streamlit
- Google Gemini API
- LangChain
- FAISS
- Retrieval-Augmented Generation (RAG)

## Features
- Ask questions from study material
- Flashcards generation
- Quiz generation
- Subject prediction
- RAG-based contextual answers

## Tech Stack
- Python
- Streamlit
- Gemini API
- LangChain
- FAISS
